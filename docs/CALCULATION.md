# 計算の定義 v4

製造部分の定義・公表値・推定式は[MANUFACTURING.md](MANUFACTURING.md)。プリウスのHEV電池製造も初期値と内訳へ別計上します。

内部単位はkg-CO₂e、km、年、L、kWh。丸めるのは表示時のみです。

- 年間距離 = 1日の距離 × 365。
- ガソリン使用量 = 距離 ÷ km/L。燃焼 = 使用量 × 2.3 kg-CO₂/L。製造・輸送 = 使用量 × 上流係数（初期0.5）。
- 充電電力量 = 距離 ÷ km/kWh。電気由来排出 = 充電電力量 × 電源構成の加重係数。
- 最初の電池製造 = kWh × kg-CO₂e/kWh（初期90）。車体製造とは別に加算。
- 交換を選び、使用年数が10年を超える場合だけ、10年の時点で同容量の電池製造を1回加算。10年で使い終わる場合は交換しない。交換前の累積値は変えない。
- 累積合計 = 初期製造 + 使用分 + その時点までに発生した交換分。

電源構成は石炭・石油・天然ガス・原子力・自然エネルギー・その他の6区分を、元表の合計で除して正規化。発電係数は820/700/490/12/50/500 g-CO₂e/kWh。
円グラフのみ最初の3区分を火力にまとめます。表示の小数第1位は最大剰余法で調整し、凡例の和を100.0%にします。計算には元の正規化比率を使います。

燃費・電費・電源構成・排出係数は全期間固定。実走行補正1.1や充電補正1.02は追加していません。WLTCの交流電力量消費率と米国サイトの値には試験条件の違いがあり、統一試験の比較ではありません。
逆転点は交換前後の各直線区間で求めます。交換時の跳びによる大小関係の変化と、合計が一致する点を区別します。SVGの丸印には曲線と同じ座標変換を適用します。

廃棄・整備・道路建設、電池化学や製造地、送配電の詳細、将来の電源改善は含めません。特定車種の認証LCAや購入判断用の精密計算ではありません。
