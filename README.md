# くるまのCO₂e実験室 v4

中学生が身近な車を入口に、走行距離・使用年数・電源構成が排出量に与える影響を考える教材です。
車名・写真とメーカーの燃費・電費等の参考値を使います。Volvoの製造部分は公表LCAの転記。他車の製造は資料と参考重量から推定した学習用モデル。推定方法はdocs/MANUFACTURING.md。使用分は全車共通の簡易計算。

## 使う

フォルダーごと保存し、index.htmlをブラウザで開きます。インストール不要。写真・スクリプト・スタイルは同梱し、出典リンクを開く以外に外部通信を必要としません。
公開するときはindex.html、assets、css、jsを同じ構成で配置してください。写真のクレジットと出典説明を残してください。

初期値は10 km/日・10年・非ハイブリッド乗用車14 km/L・サクラ・日本。距離5/10/40/100 km、年数1～30、ガソリン車4種類、EV5種類（Volvo EX30の公表LCA2仕様を追加）、G7＋中国を選べます。

## 検証と資料

Node.jsで `npm test` または `node tests/model.test.js`。外部パッケージ不要。
計算の定義はdocs/CALCULATION.md、データ出典はdocs/SOURCES.md、確認範囲はdocs/VALIDATION.mdに記載。
授業前に実際の学校端末で表示と操作を確認してください。
